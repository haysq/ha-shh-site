# ha-shh.com website

Source of [ha-shh.com](https://ha-shh.com/), the website of **ha!shh**, an offline Android app that holds the notifications you choose and delivers them together at the times you set. The app itself is not open source; this repository holds only the website and its translations.

The site is plain static HTML generated by a small Python script. No frameworks, no trackers, no external scripts.

## Languages
English, Türkçe, العربية, Deutsch, Español, Français, हिन्दी, Bahasa Indonesia, Português, Русский.
Every language has one file in `texts/` (for example `texts/de.json`). English (`texts/en.json`) is the reference.

## Build
Requires Python 3.8+ and nothing else.

```bash
python3 check_texts.py      # validate all translations
python3 build.py            # writes the site to ./public_html
```

`build.py` refuses to build if `check_texts.py` fails.

## Structure
- `texts/xx.json`: all text for one language
- `templates/`: page templates (`shell.html` wraps every page)
- `static/`: files copied as they are (CSS, JS, logos, `.htaccess`, `robots.txt`, `llms.txt`)
- `build.py`: generates `/xx/`, `/xx/features/`, `/xx/privacy/`, `/xx/faq/` for every language, plus the language-detecting root page and `sitemap.xml`
